# Формат файла кампании

Кампания — это текстовый файл `*.ini` в кодировке UTF-8. Его можно написать в Блокноте. Готовый пример — `campaigns\severnaya-marka.ini`, встроенная кампания написана в том же формате (`src\builtin_campaign.cpp`).

## Куда класть

- `campaigns\` рядом с `Security Quest.exe` — кампании, которые идут с программой (обновляются вместе с ней).
- `data\campaigns\` — ваши. Кнопка «Папка кампаний» на странице «Кампания» открывает её.

После копирования файла нажмите «Перечитать» на странице «Кампания». Если в файле ошибка, программа покажет её с именем файла и раздела, а остальные кампании загрузятся как обычно. Файл с тем же `id`, что у поставляемой кампании, заменяет её. Так можно поправить баланс под себя.

## Правило, которое нельзя нарушать

**Не меняйте `id` кампании и `id` рубежей после того, как начали проходить кампанию.** Прогресс хранится по ним: переименованный рубеж станет «не взятым». Тексты, силу врагов, требования и награды менять можно в любой момент: всё пересчитается.

## Разделы

Строки, начинающиеся с `;`, — комментарии. Каждое значение — одна строка.

### `[campaign]` — обязательно

| Ключ | |
|---|---|
| `id` | латинские строчные буквы, цифры, `-`, `_`; до 40 символов. Уникальный |
| `title` | название |
| `author`, `description` | необязательно; видны в подсказке при выборе |
| `prologue`, `epilogue` | необязательно; начало и конец летописи |

### `[chapter.<ключ>]` — главы, хотя бы одна

Главы идут в порядке появления в файле. `<ключ>` — любое слово или число, на него ссылаются рубежи.

| Ключ | |
|---|---|
| `name` | название (обязательно) |
| `intro` | текст главы в летописи |
| `color` | цвет земли и монстров: `R, G, B` от 0 до 255 |
| `x`, `y`, `radius` | положение на карте; без них главы встают в ряд сами |

### `[frontier.<id>]` — рубежи, хотя бы один

Рубежи открываются по одному в порядке появления в файле. `<id>` — любое слово без пробелов, например `1.1` или `2.1a`. Игрок видит не id, а номер по порядку внутри главы: третий рубеж второй главы — `2.3`, как бы он ни назывался в файле. Поэтому новый рубеж можно вставить между старыми, не трогая их id: прогресс сохранится, а номера сдвинутся.

| Ключ | По умолчанию | |
|---|---|---|
| `chapter` | — | ключ главы (обязательно) |
| `name` | — | название (обязательно) |
| `intro`, `victory` | — | текст до боя и короткий итог победы |
| `story` | — | сюжетная сцена после победы: 2–3 предложения, которые двигают историю дальше. Показывается на странице летописи сразу после боя и пишется в летопись; без неё — только `victory` |
| `level` | 1 | рекомендуемый уровень героя (1–99). Не требование: показывается подсказкой, а пройти рубеж мешает только слабая армия |
| `armor` | 0 | нужный уровень брони (0–5) |
| `weapon` | 0 | нужный уровень оружия (0–5) |
| `walls` | 0 | нужный уровень стен (0–3) |
| `spell` | — | нужное заклинание: `fire`, `bless`, `light`, `storm`, `seal`. Если среди врагов есть босс, без этого заклинания он неуязвим |
| `defense` | нет | `да` — оборонительный бой: стреляют стены |
| `gold` | 0 | добыча за победу |
| `x`, `y` | — | положение на карте; без них рубежи встают дугой вокруг главы |
| `enemy1` … `enemy9` | — | враги, хотя бы один |

### Враг

```
enemy1 = Имя; количество; здоровье; атака; защита; урон; скорость; признаки
```

- **урон** — число (`7`) или диапазон (`4-7`);
- **скорость** — от 1 до 20: кто быстрее, тот ходит раньше. Это же число клеток, на которое отряд идёт за ход по полю 12 × 8; у войск героя скорость 4–8;
- **признаки** — необязательно, через запятую:
  - `стрелок` — бьёт с места без ответного удара, вполсилы дальше 6 клеток и когда рядом враг;
  - `летун` — перелетает камни и отряды;
  - `натиск` — +7% урона за каждую клетку, пройденную перед ударом;
  - `без ответа` — атакованный им отряд не отвечает ударом;
  - `дальнобой` — стрелок без штрафа за дальность;
  - `босс` — рисуется крупнее, и его можно защитить заклинанием (`spell`).

Враги встают у правого края поля, войска героя — у левого, камни раскидываются сами.

## Ориентиры для баланса

Сила армии героя по неделям ровной работы (восемь миссий сложности 1–4, миссия сложности 5 раз в две недели):

| Неделя | Уровень героя | Сила армии |
|---|---|---|
| 1 | 2 | ~1200 |
| 3 | 5 | ~1900 |
| 6 | 7 | ~2800 |
| 10 | 9 | ~2900 |
| 14 | 11 | ~3600–4200 |

Сила отряда врага ≈ `количество × (здоровье + урон_средний × 3 + атака × 2 + защита × 2)`. Рубеж стоит делать примерно равным армии героя на той неделе, когда игрок до него дойдёт.

Командой `sq game` видно силу каждого рубежа, а `sq game campaigns` проверяет файлы и показывает ошибки.
